2. **`vite.config.ts`**: đổi `defineConfig` sang `vitest/config`, thêm block `test` (environment `jsdom`, setupFiles, include pattern `src/**/*.{test,spec}.{ts,tsx}`).

4. **`src/test/setup.ts`** (mới): import `@testing-library/jest-dom/vitest` + auto `cleanup()` sau mỗi test.
