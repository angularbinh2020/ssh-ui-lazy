## Fix lỗi "Element type is invalid: got: object" khi chọn pod (LogTabPanel)

### Nguyên nhân

`ansi-to-react@6.1.6` là package CJS thuần (lib/index.js set `__esModule` + `exports.default = Ansi`). Pre-bundler của Vite 8 xuất chunk `node_modules/.vite/deps/ansi-to-react.js` với `export default require_lib()` — tức **default export là cả module object** `{ default: AnsiFn }` (metadata đánh dấu `needsInterop: true` nhưng không được unwrap). Kết quả: trong dev server, `import Ansi from "ansi-to-react"` trả về object thay vì component → React ném `Uncaught Error: Element type is invalid: ... got: object` ngay khi render `LogTabPanel` (mở tab log của pod).

### Thay đổi

1. **`src/components/LogTabs.tsx`**: unwrap default import chủ động —
   ```ts
   const _AnsiModule = AnsiDefault as AnsiModule;
   const Ansi = _AnsiModule.default ?? _AnsiModule;
   ```
   Hoạt động đúng ở cả 3 môi trường: Vite dev (default = module object → `.default` là hàm), Vite build/rollup và Vitest (default đã là hàm → fallback giữ nguyên).

2. **`src/components/LogTabs.test.tsx`** (mới): regression test render `LogTabs` với dòng log chứa mã ANSI.

## Fix lỗi container name dính escape sequence (`[103;5u2004l...`) khi chọn pod

### Nguyên nhân

Shell remote chạy qua PTY (`xterm-256color`, ssh.rs) phát các ANSI escape sequence điều khiển xen kẽ output lệnh kubectl — ví dụ bracketed paste `\e[?2004l` và kitty keyboard protocol `\e[?103;5u` (đến không đồng bộ, chèn giữa output). Các hàm parse trong `kubectl.rs` không lọc byte escape nên một dòng như `\e[?103;5u\e[?2004lmogivi-website` bị nhận nguyên làm tên container, sau đó được nhét vào lệnh `kubectl logs -f -c '...'` → kubectl báo `error: container ... is not valid for pod`.

### Thay đổi

1. **`src-tauri/src/kubectl.rs`**: thêm hàm `strip_ansi()` — loại bỏ CSI (`ESC [ ... final`), chuỗi string-type OSC/DCS/PM/APC (kết thúc BEL hoặc ST), và escape 2 byte (`ESC (B`, `ESC =`...), giữ nguyên text thường + UTF-8.
2. Áp `strip_ansi()` ở đầu 3 hàm parse: `parse_pod_rows`, `parse_container_names`, `parse_contexts`.
3. **`src-tauri/src/ssh.rs`** (`run_command`, dòng ~500): strip trước `cut_at_marker` — một chỗ chặn chung cho mọi output lệnh (search pod, lấy container, get-contexts).
4. Test mới (4 test): `strip_ansi_sequences`, `parse_containers_ignores_ansi_garbage` (tái hiện đúng bug thực tế), `parse_rows_ignores_ansi_garbage`, giữ test cũ.
